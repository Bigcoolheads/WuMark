WuMark · 无码

无干扰 · 极简 Markdown 编辑器

基于 Electron 构建的桌面 Markdown 编辑器，拥有双栏实时预览、三种视图模式、 语法高亮、图片拖拽粘贴等特性。单文件便携免安装。

Features

为什么选择 WuMark？

轻量、专注、开箱即用——为 Markdown 写作而生。

◫

双栏实时预览

左侧编辑右侧渲染，输入即所见。支持拖拽调节分栏比例。

✎

三种视图模式

编辑 / 预览 / 双栏，一键切换，适应不同写作场景。

📦

单文件便携

打包为单个 exe，无需安装，开箱即用。支持 .md 文件关联。

💾

自动保存

文件菜单中开启自动保存，不再丢失内容。

🔒

关闭保护

未保存时弹出自定义对话框，提供保存 / 丢弃 / 取消三个选项。

🌓

深/浅色模式

支持深色与浅色主题切换，保护视力，适配不同环境光线。

⌨

快捷键支持

Ctrl+S 保存、Ctrl+O 打开、Ctrl+N 新建、工具栏一键插入语法。

🎨

语法高亮

预览区代码块支持 highlight.js 语法高亮，覆盖主流编程语言。

📑

多标签页

同时打开多个文件，标签栏一键切换。重复文件自动定位已有标签。
